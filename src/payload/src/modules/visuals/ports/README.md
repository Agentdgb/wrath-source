# Native visual runtime

SwingAnimation preserves six native first-person animation curves, handedness, offhand filtering and item use, with balanced matrix scopes and original Java exceptions.

The central frame pump installs hooks after module settings are published. WorldParticles and TargetESP share the depth-tested world pass. No death status observer, atmosphere, falling petals, slow swing or sword cosmetics remain in the runtime. GPU textures are released on the owning rendering context before cache teardown.

Shared embedded resource lookup lives in core/assets/EmbeddedResource.cpp. The remaining world pass only loads the effects atlas.
